# Slowbatch Studio

Static site for recipes, shop, and the Monthly Recipe Card Mail Club.

## Routes

| Path | File | Purpose |
|---|---|---|
| `/` | `index.html` | Studio homepage — trending recipes & hub |
| `/mailclub/` | `mailclub/index.html` | Mail Club subscribe / link hub |
| `/this-month.html` | `this-month.html` | Monthly mail batch status |
| `/contact.html` | `contact.html` | Contact form |

Open locally with any static server, or deploy the folder to Cloudflare Pages / GitHub Pages.
